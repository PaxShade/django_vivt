# Тесты к практической работе 3

Продолжайте проект ACME из второй работы. Сохраните предыдущие тесты вне проекта, затем замените папку `tests`, файлы `pytest.ini` и `requirements-test.txt` содержимым этого архива. Они должны находиться рядом с `manage.py`, без дополнительной внешней папки. Не объединяйте комплекты: старые проверки словаря `PRODUCTS` больше не подходят.

Установите зависимости:

```bash
python -m pip install -r requirements-test.txt
```

Запустите проверку из папки, где находится `manage.py`:

```bash
pytest
```

Тесты проверяют модель `catalog.Product`, миграции, регистрацию в admin, работу каталога с базой данных, сортировку по `id`, карточку, цену и статус, пустой каталог и ответы 404. Также сохранены проверки маршрутов, шаблонов, навигации и CSS из второй работы. В модели ожидаются `name = CharField(max_length=120)`, `description = TextField()`, `price = DecimalField(max_digits=10, decimal_places=2)` и `is_available = BooleanField(default=True)`. Метод `__str__` возвращает `name`.

Каталог показывает все товары, в том числе `is_available=False`. Контекст `products` содержит объекты `Product`, контекст `product` — выбранный объект. Названия, описания, тексты статусов и оформление выбирайте самостоятельно. Дополнительное задание с категориями тестами не проверяется.

`pytest-django` создаёт отдельную тестовую базу и применяет миграции. Тесты сами добавляют товары и тестового администратора. Они не проверяют содержимое вашей рабочей `db.sqlite3`, наличие трёх ручных записей, вашего суперпользователя или применение миграций именно к рабочей базе. Это проверьте по инструкции в практике. Не используйте `--nomigrations`.
